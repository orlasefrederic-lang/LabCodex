# Проверка «Сетевого стража» 1.1.12

Материалы проверки архива **Netstrazh 1.1.12.zip**, выполненной 29–30 октября 2026 года.

- **[Скачать все материалы одним ZIP](NetStrazh-1.1.12-review-materials.zip?raw=true)** — отчёт, логи, тесты и отдельное тестовое приложение.
- [Прочитать отчёт на GitHub](NetStrazh-1.1.12-review.md).
- [Скачать отчёт для Блокнота](NetStrazh-1.1.12-review.txt?raw=true).
- [Открыть папку с логами](logs/).
- [Инструкция по воспроизведению](REPRODUCTION.md).

Обе прежние ошибки DNS исправлены. Найден дефект применения нового запрета DNS к некоторым старым сессиям; также наблюдалась непостоянная потеря захвата после переключения VPN. В отчёте сохранены как неуспешные, так и успешные повторные проверки.

Исходники проверенной версии находятся в [архиве приложения](../../Netstrazh%201.1.12.zip). Указанные в отчёте пути `NetStrazh/app/...` и номера строк относятся к этому архиву. Код приложения при проверке не изменялся.

ZIP сохранён в исходном виде; его контрольная сумма находится в [SHA256SUMS](SHA256SUMS). В копиях Markdown для GitHub адаптированы ссылки. Пути `/workspace/...` внутри команд и исходных журналов описывают облачный стенд; для запуска на другой машине их нужно заменить своими путями, как описано в инструкции.
